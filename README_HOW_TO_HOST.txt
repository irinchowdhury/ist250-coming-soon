1 — TEST ON YOUR WINDOWS LAPTOP
- Right-click IST250_Lesson10_ComingSoon_Website.zip and choose Extract All.

- Confirm the illustrated laptop image appears, and scroll down to see three preview cards.

2 — GITHUB PAGES (FIRST DOMAIN)
- Sign in to https://github.com/ and open GitHub Desktop on Windows.
- For a user site, create a public GitHub repository named EXACTLY YOUR-GITHUB-USERNAME.github.io (replace with your actual GitHub username). Repo spelling MUST match your account username. Do not use the literal word YOUR-GITHUB-USERNAME.
- If you created the repo on github.com, use GitHub Desktop > File > Clone repository to make its local folder.
- Copy the CONTENTS of the extracted website folder into your local repository folder. index.html must be directly in the repo root, not nested in another folder.
- In GitHub Desktop, use the Changes tab: you should see index.html, styles.css, and both asset files. TAKE GITHUB DESKTOP SCREENSHOT #3 showing these files. If you have already committed, use the History tab and select the commit to display the list of files.
- Type a summary such as 'Add coming soon portfolio', click Commit to main, then Publish repository / Push origin as appropriate.
- On github.com, visit repository Settings > Pages. Under Build and deployment, set Source to Deploy from a branch, select main and /(root), then Save. If your user site is already enabled, verify the configuration.
- Visit https://YOUR-GITHUB-USERNAME.github.io/ and wait for it to go live. Open in browser with address bar visible. TAKE SCREENSHOT #1.

3 — INFINITYFREE + FILEZILLA (SECOND DOMAIN)
- Sign in or create an account at https://www.infinityfree.com/.
- Create a hosting account and choose an AVAILABLE .rf.gd subdomain. It may not be your exact personal name if already taken; confirm availability.
- Open your hosting account's FTP Details. Copy the FTP hostname and username. Use the associated FTP password. Do not share the password with anyone or put it in your screenshots.
- Open FileZilla Client. Connect using your InfinityFree FTP Details. FTP hostname comes from InfinityFree's account page; do NOT guess it from the domain URL.
- On the right (Remote site), open the correct htdocs folder for the chosen domain. If there are multiple domains, choose that domain's own htdocs. Do not upload to the parent directory.
- On the left (Local site), open the extracted webpage folder. Transfer index.html, styles.css, and the WHOLE assets folder into the appropriate htdocs folder.
- Verify right panel shows index.html, styles.css, assets/. TAKE FILEZILLA SCREENSHOT #4 showing the remote files and the application. Hide passwords or credentials.
- Visit https://YOUR-CHOSEN-NAME.rf.gd/ (or the working URL shown by your hosting control panel) and verify the same Coming Soon design appears, with its image. TAKE SCREENSHOT #2 with browser URL visible.
